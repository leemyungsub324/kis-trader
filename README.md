# kis-trader v2 — 차트 규칙 기반 다전략 자동매매

한국투자증권 Open API용 파이썬 자동매매입니다. 뉴스·실적 없이 **일봉 차트 규칙만** 씁니다.
규칙은 감으로 정하지 않고 2019~2026년 KRX 전 종목 일봉으로 검증해서 남은 것만 기본으로 켰습니다.

## 1. 검증에서 나온 결론

데이터: 코스피 보통주 857종목(상장폐지 종목 포함), 2019-01 ~ 2026-11-12.
비용: 수수료 0.015%×2 + 거래세 0.20% + 슬리피지 0.1~0.2%.

| 규칙 | 결과 | 판정 |
|---|---|---|
| 급등주를 **다음날** 추격 매수 | 5~10일 뒤 평균 −0.2 ~ −1.6% (비용 전) | 버림 |
| 급등주 **종가 매수 → 다음날 시가 매도** | 거래당 +0.3 ~ +0.5% (비용 후) | 채택 (S) |
| 시장은 멀쩡한데 **혼자 급락**한 종목 매수 | 5일 뒤 평균 −0.6 ~ −2.6% | 버림 |
| **시장 급락 중** 같이 투매된 종목 매수 | 5일 뒤 평균 +3 ~ +7%, 10일 뒤 +7 ~ +11% | 채택 (R) |
| 20/60일선 골든크로스 | 20일 뒤 −0.3 ~ +0.7% (전체 평균 이하) | 버림 |
| 일목균형표 구름 돌파·전환선 교차 | 전체 평균과 차이 없음 | 버림 |
| RSI(14) 30 미만 | 10일 뒤 +1.2 ~ +1.4% | R의 조건으로 사용 |
| 20일 신고가 돌파 스윙 | 연 −5.5% | 실험용(꺼짐) |
| 상승 추세 RSI(2) 눌림목 | 연 −8.8% | 실험용(꺼짐) |
| 변동성 돌파(CoBot 하락장 규칙) | 연 −2.3% (거래세 때문에 남는 게 없음) | 실험용(꺼짐) |

기본 조합(R + S) 백테스트, 초기 500만 원:

| 구간 | 연환산 | 최대낙폭 | 월 중앙값 | 수익 난 달 |
|---|---|---|---|---|
| 2019-07 ~ 2023-12 | +14.3% | −29.8% | +1.1% | 68% |
| 2024-01 ~ 2026-11 | +23.4% | −13.8% | +0.5% | 59% |
| 전체 | +17.9% | −29.8% | +1.0% | 66% |

연도별: 2019 +7.2 / 2020 +2.9 / 2021 +35.7 / 2022 +17.3 / 2023 +3.8 / 2024 +12.2 / 2025 +22.7 / 2026 +34.1 (%).
최악의 달은 2020년 3월 −19.7%입니다(코로나 폭락 초입에 투매 반등이 일찍 들어감).

**이 숫자를 믿을 때 알아야 할 것**

- 종가베팅(S)은 마진이 얇습니다. 슬리피지를 편도 0.3%로 잡으면 기대값이 0이 됩니다. 모의투자에서 실제 체결가와 신호 시점 가격 차이를 먼저 재야 합니다.
- 투매 반등(R)의 "시장 급락 필터"는 전체 기간 데이터를 보고 찾은 규칙이라, 2024~2026 구간도 완전히 처음 보는 데이터는 아닙니다.
- 백테스트는 종가 확정값으로 급등 신호를 판정하지만 실매매는 15시 전후 가격으로 판정합니다.
- 지수는 시총 상위 200종목 가중 수익률로 대신했습니다(실매매는 KODEX 200 사용).
- R은 1년에 몇 차례만 신호가 몰려 나옵니다. 신호가 없는 달은 수익도 0입니다.

재현: `python -m kis_trader fetch-data` 후 `python -m kis_trader backtest` (실험용 전략까지 보려면 `--all`).

## 2. 전략 규칙

**시장 국면** (KODEX 200 일봉): 종가>60일선이고 20일선>60일선이면 BULL, 둘 다 반대면 BEAR, 나머지 NEUTRAL.

**R. 투매 반등** — 3~10일 스윙, 모든 국면
- 시장 조건: 지수 5일 수익률 ≤ −4% 또는 지수가 20일 고점 대비 ≤ −7%
- 종목 조건: 5일 수익률 ≤ −15%, RSI(14) < 30, 20일 평균 거래대금 ≥ 50억
- 제외: 당일 −8% 이하이면서 거래량 3배 이상(악재성 폭락), 관리·경고 종목, 1,000원 미만
- 후보가 많으면 거래대금 큰 순으로 4종목, 종목당 자산의 20%
- 매수: 다음날 **전일 종가 −3 / −6 / −10틱에 지정가 4:3:3 분할**, 시가 갭이 −10% ~ +3% 밖이면 포기, 14:58에 미체결 취소
- 매도: +12% 익절 지정가, −15% 손절(시장가), 10거래일 지나면 청산

**S. 급등주 종가베팅** — 하룻밤 보유, BULL·NEUTRAL 국면만
- 14:58부터 코스피 전체 스캔: 당일 +7 ~ +20%, 거래량 ≥ 20일 평균의 5배, 거래대금 ≥ 50억, 현재가가 당일 범위 상단 20% 안, 20일선 위
- 종가 위치가 높은 순으로 3종목, 종목당 15%, 현재가 +3틱 지정가로 매수
- 다음날 08:50에 시장가 매도 접수 → 시가에 청산

## 3. 지정가 −3~−10틱 매수에 대해

- 투매 반등처럼 **떨어지는 종목을 받는 전략**에는 맞습니다. 시가 매수 대비 거래당 평균 수익이 비슷하거나 조금 높았습니다. 대신 체결률이 약 67%라 총수익은 큰 차이가 없습니다.
- **오르는 종목을 따라가는 전략**에는 맞지 않습니다. 아래에 걸어 둔 주문은 약한 종목만 체결되고 강한 종목은 놓칩니다. 그래서 종가베팅은 +3틱 지정가(사실상 시장가)로 삽니다.
- 손절은 항상 시장가입니다.

## 3-1. 허점 점검과 개선안 검토 (2차)

기본 규칙에서 한 가지씩만 바꿔 두 구간(2019-07~2023 / 2024~2026-11)을 함께 봤습니다. 한 구간에서만 좋아지는 안은 채택하지 않았습니다.

| 허점 | 시도한 개선 | 결과 | 처리 |
|---|---|---|---|
| 자금의 83%가 평균적으로 현금으로 놀고 있음(평균 주식 비중 17%) | 상승 국면에 남는 현금 50%를 KODEX 200에 보관 | 연 14.3→16.3% / 23.4→36.3%, 최대낙폭 −29.8→−29.8% / −13.8→−15.7% | 선택 기능 `park` 추가 |
| 폭락 초입에 너무 일찍 들어감(2020-03 한 달 −19.9%) | 지수가 오른 날에만 신호 인정 | 최대낙폭 −30→−12% / −12→−9%, 대신 연 6.8→2.5% / 12.3→3.4% | 선택 옵션 `confirm: mkt_up` |
| 변동성 큰 종목에도 같은 20% 비중 | 변동성 반비례 비중 | 최대낙폭 −30→−19% / −12→−4%, 연 6.8→2.9% / 12.3→5.3% | 선택 옵션 `vol_target` |
| 고정 틱 간격이 가격대마다 0.15~2.5%로 제각각 | ATR 배수 사다리 | 거래당 수익 1.9→2.0% / 2.6→4.6%, 체결 감소로 연 6.8→2.3% / 12.3→10.9% | 선택 옵션 `ladder_atr` |
| 하루에 4종목을 한꺼번에 진입 | 하루 신규 1~2종목 제한 | 두 구간 모두 수익 감소 | 기각 |
| 10일 고정 보유 | 5일선 회복 시 청산 | 3.3% / 18.8%로 구간별 결과가 엇갈림 | 기각 |
| 종가베팅 마진이 얇음 | 지수 방향·첫 급등·신고가·시총·거래대금·갭·요일 등 10가지 필터 | 두 구간 모두에서 일관되게 나은 필터 없음 | 필터 추가 안 함 |

(투매 반등 단독 기준 수치. 지수 ETF 보관은 ETF 매매 비용을 뺀 근사치입니다.)

정리하면 **수익을 올리는 개선은 "남는 현금 활용" 하나뿐**이고, 나머지는 수익을 내주고 낙폭을 줄이는 선택지입니다. 종가베팅은 거래의 과반이 소폭 손실이고 가끔 나오는 큰 갭이 평균을 만드는 구조라, 필터로 더 다듬을 여지가 없었습니다.

## 4. 설치와 실행

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml      # 모의투자 앱키·시크릿·계좌번호 입력
python -m pytest tests -q               # 27개 통과 확인

python -m kis_trader scan               # (전날 저녁) 일봉 캐시 생성 + 내일 후보 계산. 첫 실행은 15분쯤 걸림
python -m kis_trader run --dry-run      # 주문 없이 하루 돌려 로그 확인
python -m kis_trader run                # 모의투자 주문 시작. 08:45 전에 켜 두면 됩니다
python -m kis_trader status             # 보유·미체결·후보
python -m kis_trader report             # 전략별 실현 손익
```

- `data/STOP` 파일을 만들면 그날 신규 매수를 하지 않습니다.
- 이 프로그램이 산 종목만 관리합니다. 계좌의 다른 보유 종목은 건드리지 않습니다.
- 실전 전환은 `env: real` + `run --real-money` 두 가지를 모두 해야 주문이 나갑니다.

## 5. 모의투자 기간에 확인할 것

1. 종가베팅: `trades.csv`의 매수가가 스캔 시점 현재가보다 얼마나 높은지, 다음날 매도가가 시가와 얼마나 다른지. 왕복 0.4% 넘게 새면 끄는 게 맞습니다.
2. 투매 반등: 지정가 3단의 체결률, 익절 지정가가 실제로 체결되는지.
3. 모의투자 서버는 초당 2건 제한이라 종가 스캔이 약 8분 걸립니다. 15:18까지 못 끝내면 로그에 경고가 남습니다.
4. 모의투자 체결은 실제 호가 잔량을 반영하지 않습니다. 실전에서는 거래대금이 작은 종목의 체결가가 더 나쁩니다.

## 6. 아직 확인되지 않은 것

- 이 코드는 한국투자증권 서버에 실제로 접속해 본 적이 없습니다(작성 환경에서 접속이 막혀 있었음). API 경로·TR ID·필드명은 공식 예제 저장소와 대조했고, 주문·체결·청산 흐름은 가짜 브로커로 테스트했습니다. 첫 실행은 반드시 `--dry-run`으로 하세요.
- 종목 마스터 파일 파서도 실제 파일로는 돌려 보지 못했습니다. `scan` 첫 실행에서 종목 수가 800개 안팎인지 확인하세요.
- 코스닥은 백테스트만 지원합니다(`backtest --markets KOSPI,KOSDAQ`). 코스닥을 넣으면 거래 수는 늘지만 거래당 수익은 낮아졌습니다.

## 7. 파일 구성

```
kis_trader/
  kis_api.py      REST 클라이언트 (토큰 캐시, 호출 제한, 시세·일봉·주문·취소·체결·잔고)
  universe.py     코스피 종목 마스터 내려받기·필터
  indicators.py   이동평균·RSI·ATR 등
  regime.py       시장 국면, 시장 급락 판정
  ticks.py        호가단위 계산
  strategies/     reversal, surge (기본) / breakout, pullback, vb (실험용)
  backtest.py     일봉 포트폴리오 백테스터
  engine.py       실매매 엔진 (장전·개장·장중·마감·장후)
  cli.py          명령줄
scripts/          검증에 쓴 이벤트 스터디·변형 비교 스크립트
tests/            단위 테스트 27개
```

투자 판단과 손익의 책임은 사용자에게 있습니다. 과거 검증 결과가 앞으로의 수익을 보장하지 않습니다.
